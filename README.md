# carowolaju.com

Portfolio site for Christine Arowolaju, product designer.

- `index.html`: homepage
- `about.html`: about
- `process.html`: how I design with AI
- `work.html`: all work
- `work/`: case studies (Perfecti, JPMorgan Chase, PPL Electric Utilities)
- `assets/`: images and resume PDF
- `_redirects`: Netlify redirects from old case study URLs

Plain HTML and CSS, no build step. Deploys from the repo root.
