HOW TO PREVIEW
--------------

All tabs (Home, Projects, Experience, About) now work correctly.
"View project" buttons link to the matching case study.

TO GO LIVE (2 minutes, free)
-----------------------------
1. netlify.com/drop
2. Drag the entire "christine-portfolio" folder
3. Get a live URL instantly

ADDING YOUR IMAGES
------------------
Export from Figma → save to /images/ → reference as:
  src="../images/your-file.jpg"  (from case study pages)
  src="images/your-file.jpg"    (from index.html)
